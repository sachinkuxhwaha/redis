## Key Learnings

- **Redis Strings:** Store and retrieve key-value pairs.
- **Lists:** Add, retrieve, and remove elements.
- **Sets:** Store unique members and check membership.
- **Sorted Sets:** Store members with scores and retrieve them in sorted order.
- **Hashes:** Store and manage multiple fields under a single key.
- **Pub/Sub:** Exchange messages between publishers and subscribers.
- **Transactions:** Execute multiple commands atomically.
- **Pipelining:** Execute multiple commands in a batch to reduce network round trips.
- **Batch Operations:** Perform 1,000 Redis operations efficiently.
- **Performance Testing:** Compare individual commands with pipelined commands.
